# Changelog

All notable changes to the **Open Symlink Original File** extension by **Unit3dBranch** will be documented in this file.

This project adheres to [Semantic Versioning](https://semver.org/) and follows the [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) format.

---

## [1.0.0] - 2025-06-24

### Added

- First official release of the extension.
- Context menu item in the navigation bar **"Open the Original File"** available for a symbolic link.
- Automatic detection of symlinked files in the editor.
- Command to open the original file target directly from the editor or Explorer.
